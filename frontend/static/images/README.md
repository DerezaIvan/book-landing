# Моковые изображения

- `mock-story-garden.png` - первый разворот в анимированной книге. При замене важно сохранить ребёнка слева от центра и спокойную область справа под текст разворота.
- `mock-story-pond.png` - большая демонстрационная сцена. Финал должен оставаться читаемым при широком desktop-crop и вертикальном mobile-crop.
- `mock-founders.png` - временный редакционный портрет. В финале заменить реальной фотографией Ивана и Алины с похожим тёплым боковым светом и рабочим, а не постановочным сюжетом.

Все файлы подключены с фиксированными размерами, поэтому их можно заменять без перестройки секций: две сюжетные сцены - 3:2, портрет - 4:5.
